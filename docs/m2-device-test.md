# M2 device test — v0.2.0 (speech and translation)

Run this on a real phone after v0.2.0 is published. Tick each box or write what you saw.
Spikes S1 (speech recognition) and S4 (translation quality) from the design are sections 3 and 4.

Phone model: ____________ · Android version: ____ · Network: Wi-Fi / mobile data

## 1. Update from 0.1.0 (M1 exit check)

- [ ] 0.1.0 is installed (from the website or GitHub Releases).
- [ ] Opening the app shows **Update available · 0.2.0** with the What's new notes.
- [ ] **Update now** downloads, Android asks to install, and the app reopens on 0.2.0.
- [ ] A one-time **What's new in 0.2.0** sheet appears.
- [ ] Settings → About shows v0.2.0 (2).

## 2. First conversation

- [ ] Home → **In-person conversation** opens the conversation screen.
- [ ] If the other person's language is Automatic, the screen asks **Which language will they speak?**
- [ ] The first **Listen** shows Android's microphone dialog. After allowing, the button turns into **Stop**.
- [ ] Saying nothing shows **Didn't catch that…** and the empty card disappears.
- [ ] Back returns to Home, and the microphone indicator (top of the screen) goes off.
- [ ] Tap **Listen**, then **Stop** straight away: the screen returns to Listen/Speak (no stuck Stop button).
- [ ] Do six or more turns in a row: each new translation is fully visible without scrolling by hand.

## 5. Offline

- [ ] With Wi-Fi on, leave the app open on Home for a few minutes (offline models download in the background).
- [ ] Turn on airplane mode. Listen or Speak. Live text may stop (Google's online speech needs a connection).
      If text appears, the translation shows with the **Offline translation** chip.
- [ ] Without the downloaded models, the card says **You're offline, and offline translation isn't downloaded yet…**
      with **Try again**.
- [ ] In airplane mode, which notice appears when you tap Listen? (Network, or "speech recognition isn't
      available" if the phone has no offline speech pack.) ____________
- [ ] Turn Wi-Fi off partway through the first-run download, turn it back on, then leave and reopen the app:
      the download resumes (offline translations work afterwards).

M2 is done when: the update popup installs 0.2.0; live text appears for all three languages; all six directions
